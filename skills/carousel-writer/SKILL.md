# Skill: High-Retention Carousel Writer + Layout Strategist

Create platform-native Instagram/TikTok/LinkedIn carousels optimized for:

* retention
* readability
* saves
* shares
* mobile scanning
* cognitive ease

This skill governs:

* copy structure
* slide psychology
* visual hierarchy
* pacing
* information density
* layout guidance

Pair with:
`skills/remotion-viral-reels/SKILL.md`
for rendering/motion/animation systems.

---

# Core Principle

Do NOT design slides like mini landing pages.

Design slides for:

* thumb-stopping
* instant comprehension
* swipe momentum
* screenshotability

Every slide should be understandable in under 1 second.

---

# Golden Rules

## 1. One Idea Per Slide

Every slide must communicate ONE core idea only.

Bad:

* headline
* bullets
* proof
* CTA
* urgency
  all on one slide.

Good:
Slide = one concept only.

Examples:

* one mistake
* one framework
* one warning
* one statistic
* one CTA

---

## 2. Reduce Cognitive Load

Instagram is scanned, not read.

Use:

* short sentences
* large text
* minimal paragraphs
* whitespace
* visual grouping

Avoid:

* dense paragraphs
* excessive bullets
* stacked sections
* too many visual elements

---

## 3. Reading Velocity

Slides should be readable quickly.

Target:

* Hook slides: 1–1.5 seconds
* Value slides: 2–3 seconds
* CTA slides: under 2 seconds

If a slide takes too long:

* shorten text
* split the slide
* simplify bullets

---

# Slide Role System

Every slide must have ONE role only:

* hook
* curiosity
* warning
* proof
* mistake
* framework
* checklist
* explanation
* payoff
* CTA

Never combine multiple roles on one slide.

---

# Visual Hierarchy Rules

Each slide must contain:

1 dominant element
1 secondary element
optional supporting detail

Hierarchy order:

1. headline
2. emphasized keyword
3. supporting text
4. branding

Never allow all elements to compete equally.

---

# Layout System

Preferred structure:

TOP:

* headline

MIDDLE:

* icon OR supporting graphic

BOTTOM:

* 2–3 short bullets OR supporting sentence

FOOTER:

* subtle branding/logo

Use consistent layout systems across slides.

Do not reinvent the layout every slide.

---

# Whitespace Rules

Whitespace = premium design.

Always leave:

* large margins
* spacing between sections
* breathing room around headlines

Avoid:

* edge-to-edge text
* cramped layouts
* oversized paragraphs

---

# Color System

Use:

* 1 primary color
* 1 accent color
* white/neutral backgrounds

Avoid:

* too many bright colors
* excessive gradients
* glowing effects everywhere
* multiple competing accents

Red should be used sparingly for:

* warnings
* urgency
* mistakes

---

# Background Rules

Prefer:

* flat backgrounds
* subtle gradients
* minimal texture
* clean white space

Avoid:

* busy photos
* dark textured overlays
* noisy backgrounds
* excessive visual effects

White/light backgrounds improve readability and retention.

Recommended ratio:

* 70% light slides
* 30% dark slides

---

# Typography Rules

Use:

* large headlines
* short line lengths
* 2 font weights maximum
* clean sans-serif fonts

Avoid:

* too many font sizes
* excessive all-caps
* multiple highlighted phrases
* tiny body text

Typography hierarchy:

1. headline
2. emphasized word
3. support copy

---

# Screenshotability Rule

At least 2 slides per carousel should feel worth saving.

Good screenshot slides:

* frameworks
* checklists
* systems
* comparisons
* visual summaries
* concise educational value

If a slide cannot stand alone as a screenshot:
simplify it.

---

# Carousel Momentum

Do NOT peak on slide 1.

Slides should progressively increase:

* specificity
* value
* clarity
* payoff

Best slide is usually:
slide 4–7.

---

# Pattern Interrupt Rules

Every 2–3 slides:

* invert background color
* simplify layout
* use oversized text
* create visual contrast
* reduce elements dramatically

Avoid visual sameness.

---

# Emotional Flow

Default emotional sequence:

1. curiosity
2. recognition
3. tension
4. clarity
5. empowerment
6. action

Avoid flat informational tone.

---

# Mobile Optimization Rules

Slides must work on mobile first.

Optimize for:

* fast scanning
* immediate understanding
* thumb-stop hooks
* easy swiping

Never rely on tiny text.

---

# Platform Formatting

Instagram:

* save/share optimized
* educational
* clean layouts
* 3:4 preferred (1080×1440)

TikTok Carousel:

* bigger hooks
* more contrast
* faster pacing
* fewer words

LinkedIn:

* more whitespace
* authority-focused
* cleaner typography
* fewer emojis

---

# Design Intelligence Rules

Prefer:

* asymmetric balance
* oversized headlines
* modular layouts
* icon anchoring
* highlighted keywords
* card systems
* whitespace

Avoid:

* clutter
* too many badges
* multiple focal points
* stacked persuasion elements
* "sales page" energy

Modern high-performing carousels should feel:

* calm
* confident
* editorial
* premium

NOT:

* loud
* crowded
* overdesigned

---

# Hook Types

Each carousel should declare ONE hook type:

* mistake
* warning
* framework
* myth
* comparison
* checklist
* prediction
* secret
* authority
* trend

Visual style should match hook type.

---

# Brand Energy Profiles

Different niches require different pacing. These are STARTING POINTS;
the client's `brand.md` voice always wins over the generic profile.

Personal Injury:

* urgency
* contrast
* stronger emphasis
* (but if brand.md says "calm authority" — soften, use restraint)

Family Law:

* empathy
* softer layouts
* less aggressive visuals

Luxury Medical:

* minimal
* premium whitespace
* soft gradients

Criminal Defense:

* authority
* tension
* restrained urgency

Lemon Law:

* frustration
* clarity
* empowerment
* simplified systems

Immigration:

* clarity
* reassurance
* step-by-step

Workers' Comp:

* matter-of-fact
* knowing-the-system
* protective

Probate:

* calm
* fiduciary
* family-first

---

# Final Rule

The best carousel is NOT:
the one with the most persuasion.

The best carousel is:
the easiest to process.

Optimize for:

* clarity first
* retention second
* persuasion third
