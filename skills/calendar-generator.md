# Skill: Calendar Generator

Plan a month from `config.yml` cadence + the 5 pillars. Write `calendar/<month>.md` as a
day → pillar → format → title → platforms table.

## Balance
- Spread pillars; don't stack two MYTH days back to back.
- Lead magnets ~1–2/week (match `cadence_per_month.lead_magnets`).
- Insert ES variants for EDU + LEAD if `languages` includes `es`.
- Note batch-film days so the client films reels in 1–2 sessions.
- Map titles to real keywords from keywords.md where natural (esp. YouTube/local).
